# IONVERSE LAB — Phase 1: Core Simulation

ต้นแบบห้องปฏิบัติการอิเล็กโทรไลต์ ม.5 สำหรับ GitHub Pages (ไม่มี build tools และไม่ต้องติดตั้งแพ็กเกจ)

## เปิดใช้งาน

1. แตก ZIP และนำไฟล์ทั้งหมด (รวม `index.html` และโฟลเดอร์ `src/`) ไปใส่ใน GitHub repository
2. ไปที่ **Settings → Pages → Build and deployment → Deploy from a branch** แล้วเลือก branch `main`, โฟลเดอร์ `/(root)`
3. เปิด URL ที่ GitHub Pages แสดง หรือทดสอบในเครื่องด้วย `python3 -m http.server 8080` แล้วเปิด `http://localhost:8080`
4. **ไม่ควรเปิด `index.html` ผ่าน `file://`** เพราะ JavaScript ES modules ต้องใช้ HTTP server

## การใช้งาน

1. เลือกสาร 12 ชนิด (หรือใช้น้ำกลั่นเป็นสารควบคุม) เลือกความเข้มข้น 0.01, 0.1 หรือ 1 mol/L
2. กดกระดาษลิตมัสแดงและน้ำเงิน
3. กด `ต่อวงจร` → `จุ่มขั้วไฟฟ้า` → `เปิดสวิตช์`
4. อ่าน *Relative conductivity signal* และความสว่างของหลอด
5. เลือกประเภทสาร แล้วบันทึกผล จากนั้นกดล้างขั้วก่อนเปลี่ยนสาร
6. เปิดแท็บสมุดบันทึกและส่งออก CSV ได้; หน้า `ตรวจสอบระบบ` แสดงสถานะการตรวจเบื้องต้นของ 12 สาร

## การทดสอบโค้ด

ต้องมี Node.js 18+ เท่านั้น (ไม่ต้อง npm install):

```bash
npm test
```

## โครงสร้าง

- `src/chemistry.js`: ข้อมูลสาร, สมดุลกรด–เบสอย่างง่าย, จำนวนไอออน, ลิตมัส, คะแนนนำไฟฟ้า *สัมพัทธ์*
- `src/lab.js`: state machine สำหรับลิตมัส วงจร ขั้วไฟฟ้า การล้างอุปกรณ์ และบันทึกผล
- `src/app.js`: หน้าจอและระบบบันทึกในเครื่อง
- `src/style.css`: UI ห้องทดลองจำลอง 2D
- `tests/chemistry.test.js`: ชุดทดสอบ Node.js

## ความถูกต้องและข้อจำกัด

- เป็น **การจำลองเชิงการศึกษา** ไม่ใช่อุปกรณ์วัดจริง ไม่รายงานค่าการนำไฟฟ้าจริง (µS/cm)
- ค่า pH ใช้ Ka/Kb โดยประมาณใกล้ 25°C ในสารละลายอุดมคติ ไม่คำนวณกิจกรรมไอออนที่ความเข้มข้นสูง จึงไม่ใช่ผลพยากรณ์เชิงปริมาณที่แม่นยำ
- สัญญาณ 0–100 เป็นดัชนี *relative* จากความเข้มข้นไอออนและสัมประสิทธิ์เคลื่อนที่สัมพัทธ์ โดยจำกัดค่าบน 100 ไม่ใช่สเกลวัดจริง และไม่เทียบเครื่องตรวจเชิงกายภาพ
- ลิตมัสใช้ขอบช่วง pH แบบประมาณ (น้ำเงินเปลี่ยนแดงที่ pH<4.5; แดงเปลี่ยนน้ำเงินที่ pH>8.3) NH₄Cl ที่ 0.1 M แม้มีสมบัติเป็นกรดอ่อนๆ อาจไม่เปลี่ยนสีน้ำเงินเป็นแดงอย่างชัดเจน
- ค่าระดับความสว่างไม่สามารถใช้พิสูจน์ความแรงของอิเล็กโทรไลต์ได้โดยลำพัง โดยเฉพาะความเข้มข้นต่างกัน
- ภาพอนุภาคในบีกเกอร์เป็นสัญลักษณ์เพื่อช่วยสังเกต ไม่ใช่แผนภาพจำนวนอนุภาคตามสมดุลที่ถูกต้องเชิงสัดส่วน (Phase 2 จะทำ Particle Engine ต่างหาก)
- การล้างขั้วเป็นสถานะเตือนการปนเปื้อน **ยังไม่ได้จำลองปริมาณสิ่งตกค้างทางเคมี**
- การทดลองบันทึกใน `localStorage` เฉพาะเบราว์เซอร์ของผู้ใช้ ยังไม่มีระบบครู/Google Sheets/เข้าสู่ระบบ
- **Phase 1 ยังไม่ใช่ High Realism 3D**; เป็น mockup แบบปฏิสัมพันธ์เพื่อพิสูจน์ความถูกต้องก่อนพัฒนา Phase 2

## เป้าหมายถัดไป

พัฒนา 3D instruments และ Smart Realistic drag-and-snap พร้อมกราฟิกสูง โดยใช้ state machine และ chemistry engine ที่แยกไว้
